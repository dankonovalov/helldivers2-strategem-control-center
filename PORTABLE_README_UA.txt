HELLDIVERS 2 STRATAGEMS - PORTABLE
=================================

УКРАЇНСЬКА
-----------

Вимоги:
- Windows 10 або новіша.
- Elgato Stream Deck 6.6 або новіша.
- Stream Deck або Stream Deck Mobile.

Встановлення:
1. Повністю розпакуйте ZIP у звичайну папку.
2. Запустіть Helldivers2-Stratagems-Control.exe.
3. Перемикайте мову кнопкою EN / UA у верхній панелі.
4. Виберіть монітор та область із чотирма іконками loadout.
5. Збережіть налаштування і запустіть парсер.
6. Відкрийте com.super-earth.helldivers2.streamDeckPlugin і встановіть плагін.
7. Додайте Stratagem Slot 1-4 у застосунку Stream Deck.

Клавіші гри за замовчуванням:
- меню стратагем: Left Ctrl;
- Up: W, Down: S, Left: A, Right: D.

Як це працює:
- GUI розпізнає чотири іконки та зберігає підтверджений стан.
- У списку під кожним слотом можна вручну вибрати кандидата з низьким збігом;
  виберіть "Автоматичний вибір", щоб повернути автоматичне розпізнавання.
- Плагін Elgato показує іконки на кнопках.
- Натискання кнопки вводить відповідний код із затиснутим Left Ctrl.
- Порожній екран не очищає останні підтверджені кнопки.

Налаштування зберігаються в:
%LOCALAPPDATA%\HelldiversStratagems

Не переміщуйте EXE окремо. Папки _internal, locales і stratagem_library мають
залишатися поруч із ним.

ENGLISH
-------

Requirements:
- Windows 10 or newer.
- Elgato Stream Deck 6.6 or newer.
- Stream Deck or Stream Deck Mobile.

Installation:
1. Extract the complete ZIP archive into a regular folder.
2. Run Helldivers2-Stratagems-Control.exe.
3. Switch languages with the EN / UA button in the top bar.
4. Select the monitor and the area containing all four loadout icons.
5. Save the settings and start the parser.
6. Open com.super-earth.helldivers2.streamDeckPlugin and install the plugin.
7. Add Stratagem Slot 1-4 in the Stream Deck application.

Default game controls:
- stratagem menu: Left Ctrl;
- Up: W, Down: S, Left: A, Right: D.

How it works:
- The GUI recognizes four icons and stores the confirmed state.
- The list under each slot lets you manually select a low-confidence candidate;
  select "Automatic selection" to resume automatic recognition.
- The Elgato plugin displays those icons on its buttons.
- Pressing a button enters the corresponding code while holding Left Ctrl.
- An empty screen does not clear the last confirmed buttons.

Settings are stored in:
%LOCALAPPDATA%\HelldiversStratagems

Do not move the EXE by itself. Keep the _internal, locales, and stratagem_library
folders next to it.
